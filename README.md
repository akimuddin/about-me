# AkimTech — Professional Web Developer Portfolio

A responsive, high-performance single-page portfolio template built for web developers, freelancers, and agency professionals. Designed with a dark UI theme, cyan accents (`#00c3ff`), smooth scroll interactions, and dynamic user experience elements tailored for marketplace client acquisition (Fiverr, Upwork, direct clients).

![AkimTech Portfolio Banner](image_bb729f.png)

---

## ✨ Features

* **Scroll Reading Progress Bar:** Displays real-time scroll completion percentage at the top of the viewport.
* **Smart Navigation Sync:** Auto-highlights active navbar links with a solid cyan background as you scroll through sections or click navigation items.
* **Smooth One-Time Animations:** Integrated `IntersectionObserver` with `Animate.css` to trigger crisp entrance animations once as users scroll down.
* **Interactive Typewriter Effect:** Dynamic headline rotation highlighting key core competencies.
* **Filterable Portfolio Grid:** jQuery-powered project filtering by category (Web Development, WordPress, All).
* **Comprehensive Contact Section:** Structured lead-capture form featuring custom inputs for project budgets, service selection, and technical requirements.
* **Responsive Layout:** Mobile-first architecture built on Bootstrap 5 grid utilities.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), jQuery 3.7
* **Framework:** Bootstrap 5.3
* **Animations:** Animate.css, JavaScript `IntersectionObserver` API
* **Icons:** Font Awesome 6.4
